# Photo Décalage

Une petite application web qui permet de choisir ou prendre une photo, de la découper en 16 bandes verticales, puis d’inverser l’ordre des bandes de droite à gauche.

L’application fonctionne entièrement dans le navigateur : la photo reste sur l’appareil et n’est envoyée vers aucun serveur.

## Test local

Ouvrir `index.html` dans Chrome ou lancer un serveur statique dans le dossier du projet.
